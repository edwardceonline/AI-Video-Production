# EzSites — 27-second business-first commercial (draft)

**Watch the GitHub Actions rendered MP4.** This is a creative treatment; not a verified product demo. Run `npm install`, `npm run studio`, `npm run render` after downloading source assets (the workflow downloads them during build).

## Concept and timeline

- 0–5s — A real florist at work. **YOU BUILT THE BUSINESS.** No scene index, breadcrumbs, numbers, decorative labels.
- 5–11s — A website demonstration for the fictional floral brand Petal & Paper. The flower photography is real licensed stock; the layout is an illustrative website, *not a capture of a customer website or EzSites app*.
- 11–15s — Domain-name storytelling, `petalandpaper.ch` **illustrative text**, not a registered or available domain.
- 15–19s — Illustrative business email message; not the EzSites inbox UI.
- 19–23s — Contact-form narrative, illustrative but a supported capability.
- 23–27s — Real EzSites logo and CTA; bright, readable hold.

Music is algorithmically composed in-repository. Voice-over is generated at render time for a **draft only**; the free TTS voice is subject to separate commercial-use clearance before publishing an advertisement.
