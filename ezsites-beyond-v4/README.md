# EzSites V4 | Beyond Your Doors

30-second commercial in English built in Remotion. Distinct from previous V3: narrative customer journey **real-world business → discovery → web presence → web identity → inquiry → professional email → EzSites**.

Includes public Kurotsuki production-site screenshots captured via Playwright, original music generated in Python, English voice-over with neural TTS, and two free-to-use cinematic Pexels clips (source IDs 8908334, 7550763). External footage remains as generated CI assets rather than being redistributed in source control. Preview domain is deliberately not committed.

Illustrative inquiry/email typography is motion graphics, **not** a screenshot of an EzSites mailbox. Real website screenshot is a documented published demo, not a claim of verified restaurant business information. Do not claim booking integrations or guaranteed outcomes.

Run GitHub Actions workflow `ezsites-v4-beyond.yml` on feature branch. MP4 uploaded as GitHub Actions artifact with QA stills.
